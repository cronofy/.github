## Temporal infrastructure for agents, systems and teams

Agents act. Systems record. Teams decide. Time is the constraint they can't escape.

Cronofy is the orchestration layer that keeps workflows in step — meetings, actions and decisions on the same tempo. An enterprise-proven grid that unifies availability control, coordinates the full scheduling lifecycle, and unlocks meeting intelligence. Over 180,000 businesses worldwide build on it.

## What you can build with Cronofy

Each capability runs independently or together, all powered by the same temporal grid.

[**Calendar API**](https://www.cronofy.com/developer?utm_source=github&utm_medium=profile&utm_content=products-calendar-api)

A unified API for Google, Microsoft, and Apple calendars, including on-premise Exchange. Real-time push notifications, full sync or free/busy access, and a 99.99% service guarantee. Cronofy handles authorization and syncing as a single intermediary, so teams don't maintain a separate integration for each provider.

[**White Label API**](https://www.cronofy.com/developer?utm_source=github&utm_medium=profile&utm_content=products-white-label-api)

Modular endpoints for teams who need full control over custom meeting workflows. Built for complex multi-user coordination, edge cases, and bespoke business logic — keeping users inside a fully native, branded experience.

[**Embedded Scheduler**](https://www.cronofy.com/developer/scheduler-api?utm_source=github&utm_medium=profile&utm_content=products-embedded-scheduler)

The fastest way to add scheduling to a product. A pre-built, fully managed solution that drops in via the Cronofy Embed NPM package. Supports multi-person, multi-event, rescheduling, and complex selection rules, with client and server-side callbacks for every booking event.

[**Meeting Agents**](https://www.cronofy.com/meeting-intelligence?utm_source=github&utm_medium=profile&utm_content=products-meeting-agents)

One API to record, transcribe, and summarize meetings across Zoom, Google Meet, and Microsoft Teams. White-labeled agent name and avatar, 30+ languages, regional data residency, and no third-party subprocessors. Attach an agent directly to a calendar event when scheduling through Cronofy, and it stays aligned if the meeting moves.

[**MCP Server**](https://www.cronofy.com/developer?utm_source=github&utm_medium=profile&utm_content=products-mcp-server)

Give AI agents direct access to scheduling, availability, and meeting context. The agentic toolkit for teams building autonomous workflows on top of the temporal grid.
